# Artifacts

This directory contains project media and selected QA captures. These files are reference material; the application build and runtime do not read them.

- `nexora-fanpage-cover.png` and `nexora-logo-avatar.png` are the Nexora fanpage images.
- `nexora-fanpage-design-notes.md` keeps the notes that accompanied those images.
- `qa/` contains screenshots and logs from manual verification runs, grouped by feature or run.

Temporary local files belong in `tmp/`, which is ignored by Git.
